# bigint

作者：张明栩

创建时间：2026.9.19

当前版本：v0.3

一个轻量的 C++ 高精度整数运算库，支持数千至数万位十进制整数的基本运算。

## 支持的功能

| 函数                   | 说明                           | 备注                 |
|----------------------|------------------------------|--------------------|
| `add(s1, s2)`        | 高精度 + 高精度                    | 已完成                |
| `sub(s1, s2)`        | 高精度 - 高精度                    | 已完成                |
| `mul(s1, s2)`        | 高精度 × 高精度                    | 已完成                |
| `mul(s, n)`          | 高精度 × 单精度（`n` 为 `long long`） | 此功能暂缓              |
| `div_dec(n1, n2, p)` | 单精度 ÷ 单精度，保留 p 位小数（四舍五入）     | 此功能暂缓              |
| `div_dec(s, n, p)`   | 高精度 ÷ 单精度，保留 p 位小数（四舍五入）     | 此功能暂缓              |
| `div_dec(s1, s2, p)` | 高精度 ÷ 高精度，保留 p 位小数（四舍五入）     | 已完成,当前除法计算部分仍有优化空间 |
| `div_rem(s, n)`      | 高精度 ÷ 单精度，返回商和余数             | 此功能暂缓              |
| `div_rem(s1, s2)`    | 高精度 ÷ 高精度，返回商和余数             | 已完成,当前除法计算部分仍有优化空间         |


## 精度范围

当前核心运算使用 `std::vector` 动态存储中间结果，
不再受固定数组容量限制。

理论上整数位数主要受运行环境可用内存限制。
当前版本主要面向 ACM / 算法竞赛中的数千至数万位十进制整数运算。

## 快速开始

```cpp
#include "bigint.h"
#include <iostream>

int main() {
    using namespace bigint;

    std::cout << add("123456789", "987654321") << '\n';
    // 1111111110

    std::cout << mul("12345678901234567890",
                     "1000") << '\n';
    // 12345678901234567890000

    std::cout << div_dec("123456789", "7", 5) << '\n';
    // 17636684.14286

    auto r = div_rem("123456789", "7");
    std::cout << r.quotient << " " << r.remainder << '\n';
    // 17636684 1
}
```

## 项目目标

本项目主要用于 ACM / 算法竞赛中的高精度运算。

目标是将常见的高精度算法封装成可复用的 C++ 接口，
 避免在不同题目中重复编写高精度模板。
